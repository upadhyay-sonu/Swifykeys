# 🚀 Typing Speed Tester (React Native)

A modern **Monkeytype-like typing speed tester app** built with React Native (Expo), designed with AI-based insights, analytics, and gamification.

---

## 🔥 Features

### ⚡ Core

* Real-time typing test
* WPM (Words Per Minute) calculation
* Accuracy tracking
* Error highlighting

### 🧠 AI-Based Features

* Smart difficulty adjustment
* Personalized word suggestions
* Error pattern tracking

### 📊 Analytics

* Typing speed graph
* Accuracy trends
* Heatmap of wrong keys

### 🎮 Gamification

* XP system & levels
* Daily challenges
* Streak tracking

### 🌍 Social

* Leaderboard (planned)
* Share results

### 🎙️ Unique Features

* Code typing mode 💻
* Multilingual typing (Hindi + English)
* Voice vs typing comparison

---

## 🛠️ Tech Stack

* React Native (Expo)
* JavaScript
* AsyncStorage
* React Native Reanimated

---

## 📦 Installation

```bash
git clone https://github.com/upadhyay-sonu/Swifykeys.git
cd Swifykeys
npm install
npx expo start
```

---

## 📱 Run on Web

```bash
npx expo start --web
```
